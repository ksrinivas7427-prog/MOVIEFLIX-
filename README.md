Movieflix:-
### Project Description

**MovieFlix – Advanced Movie Search and Recommendation System** is a DSA-based project designed to provide fast and efficient movie searching and discovery 
from a large collection of movies. The system allows users to search movies by title, actors, genres, keywords, ratings, and release year. In **Phase 1**, 
the project focuses on **Pattern/String Searching using the Z-Algorithm, Z-Function, and Z-Array (Z-Mapping)**. Movie information is stored in a text file 
and loaded dynamically by the Java program, allowing the Z-Algorithm to search actual movie titles rather than using hard-coded data.

The project will progressively incorporate both **normal and advanced DSA concepts**, including arrays, linked lists, stacks, queues, searching, sorting, 
hashing, BST, AVL trees, tries, heaps, graphs, and LRU caching. These techniques will be used for features such as autocomplete, efficient searching, sorting, 
top-rated movies, trending movies, watch history, and movie recommendations. The main objective is to demonstrate how DSA algorithms can be practically applied 
to build an efficient, scalable, and user-friendly movie search and recommendation system.
